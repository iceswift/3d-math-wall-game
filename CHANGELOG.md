# Changelog

## 1.0.0 — 2026-10-24

First portfolio release of 3D Math Wall.

- Classic, Time Attack and Daily Challenge modes.
- Interactive tutorial and configurable practice mode.
- Procedural 3D environment, number-shaped walls and synthesized sound.
- Achievements, cosmetic progression and number customization.
- Accessibility options and local best scores.
- Animated result ranks, score count-up and personal-best celebration.
- Portfolio documentation and gameplay screenshots.
- Puzzle tests, syntax checks and automated GitHub Pages deployment.

Known limitations: saves are browser-local; no online leaderboard; daily dates use local timezones; broad mobile performance testing remains future work.
